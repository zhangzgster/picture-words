# 看图说英语 · Picture Words

An interactive English vocabulary website with 40 picture cards covering body parts, clothing, footwear and accessories.

## Features

- See the picture first; click to reveal the English word and Chinese meaning.
- Listen to English pronunciation using your device's speech synthesis.
- Shuffle cards and practise in focus mode (Space to reveal, arrow keys to navigate).
- Track mastered words locally in your browser.

## Run locally

Serve this directory with any static web server, for example `python3 -m http.server 8000`, then open http://localhost:8000.

No build step, dependencies or API keys are required. Keep `index.html`, `app.js`, and `style.css` together.

## Deployment

GitHub Pages publishes the root of the `main` branch. Changes committed to that branch are deployed automatically.

Learning progress is stored per browser and website address; progress from the original site does not automatically transfer here.
